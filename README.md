# 🗺️ Random Map Generator (v1.0.1)

A lightweight, browser-based procedurally generated terrain map generator powered by JavaScript, HTML5 Canvas, and multi-layered noise functions.

---

## ✨ Features

- **Procedural Terrain Generation**: Employs multi-layer noise algorithms to procedurally build terrain elevation, moisture maps, landmasses, and rivers.
- **Master 4K Engine (Ultra HD)**: Generates high-resolution terrain textures at up to 4K resolution natively in the canvas.
- **Smooth Downsampled Exports**: Supports downloading maps in `1x (Standard)`, `2x (HD)`, `3x (Full HD)`, and `4x (Ultra HD / 4K)` with high-quality image smoothing.
- **Multiple Themes**: Features built-in themes including **Classic**, **Forest**, **Ocean**, **Desert**, and **Night**.
- **Seeded Worlds**: Custom seeds allow you to recreate or share identical map layouts anytime.
- **Responsive Mobile & PC UI**: Optimized for mobile and desktop screens with a clean card-based design.
